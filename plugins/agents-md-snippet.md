## Persistent Memory service

The user's prior decisions, preferences, project history, and personal context
live in a typed wiki published by the namespace-native Memory service. Before
acting on a topic that may have prior context, use the `recall` skill to search
and read the private local `memory` projection with r9p.

Use the `create` skill only when the user explicitly asks to remember, update,
forget, or delete persistent knowledge. Never write a host-local wiki. Memory
owns validation, atomic Git mutation, automatic transcript maintenance, and
publication.
